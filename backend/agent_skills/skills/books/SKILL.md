# Навык: Книги

Читалка книг пользователя. Текст книг лежит на сервере, поэтому у тебя есть вся книга,
а не только присланный фрагмент. Инструменты: `list_books`, `book_chapters`,
`read_chapter`, `search_book`, `list_highlights`.

Как отвечать:
- Вопрос приходит из читалки вместе с книгой, главой и цитатой. Этого хватает, чтобы
  перевести или объяснить фрагмент — лишних вызовов тогда не делай.
- Если вопрос выходит за цитату («где ещё об этом», «а раньше он не говорил обратное?»,
  «что там дальше») — ищи `search_book` и читай `read_chapter`. Не отвечай по памяти о
  книге и не пересказывай общее знание о ней вместо текста.
- Ссылайся на место: номер и название главы, короткая цитата. Не выдумывай цитат —
  приводи только то, что вернули инструменты.
- Читай экономно: сначала `search_book`, и только потом главу целиком, если правда нужна.
  Главы отдаются кусками, `more=true` — есть продолжение по `next_offset`.

Выписки:
- `list_highlights` — что человек уже отметил в книге. Цвет несёт смысл: Важное,
  Не согласен, Вопрос, В вики, Красиво сказано. Сводку по книге собирай из них.
- Выписку в базу знаний сохраняй навыком `wiki`: страница про книгу, аккуратно
  оформленная цитата, ссылка `[[имя]]` на смежные страницы. В ответе — одна строка,
  куда положил.

Ничего в книгах не меняй: файлы книг, прогресс и выписки правит сам пользователь
в читалке.
